Running it

Nothing to install and nothing to build. Open any index.html from disk, or serve this folder with any static server. The logic modules are DOM-free, so the tests run under Node's built-in runner: 

node --test "projects/<slug>/*.test.js"

Conventions shared by every project are in projects/SPEC.md.
