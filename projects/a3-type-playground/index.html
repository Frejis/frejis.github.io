    What is actually happening
    
  
    
    
    
      
    Fresh variables
    
      
    When the checker meets \x -> ... it has no idea what
      x is, so it writes down a and carries on.
    
    
    
    
    
      
    Constraints
    
      
    Using x forces the issue. x + 1
      means a ~ Int. Unification solves those equations, or fails with a reason.
    
    
    
    
    
      
    Generalization
    
      
    A let-bound function whose type still has free variables can be
      used at several types at once. That is why id 1 and
      id true both work.
