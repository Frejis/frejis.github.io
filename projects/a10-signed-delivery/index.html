Signed Delivery

A signature does not just prove a message wasn't changed - it proves who could have made it. This page signs a real message with a real key, then breaks that guarantee three different ways so you can see exactly what each one relies on.

Part 2 · the trust chain

  

    One valid signature only proves a document came from whoever holds that
    key. Trusting a website or a piece of software needs a
    chain: a root you already trust vouches for an intermediate, which
    vouches for the thing you actually received. Attack any one link and
    watch the chain break exactly there - the rest keeps working.
