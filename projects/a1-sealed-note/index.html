Sealed Note

A note-sharing tool where the server storing your note is mathematically incapable of reading it. Everything below is live: encrypt on the left, watch the server's actual database on the right, then open the link back on this page to decrypt it.

The key never leaves your browser. It travels to the recipient inside the URL fragment (the part after #), which browsers never send to a server. The server only ever stores and serves ciphertext — see the table on the right.

You (in the browser)

Everything after #k= is the fragment. Try it: open your browser's network tab, click "open the link" below, and confirm no request ever carries that part.

What the server stores

This is a simulated server — an in-memory store running in this tab, persisted to localStorage so it survives a reload. These rows are exactly what a real backend's database would contain: no plaintext, ever.

Open the link

Paste a share link (or use the one generated above) to decrypt it as the recipient would.

Want to see the failure path? Expand a row on the right, click tamper with ciphertext, then open that row's link again — decryption refuses to return anything rather than handing back garbage. That is AES-GCM's authentication tag doing its job.
