Secret Ballot

A poll where the server adds up every vote without ever being able to read a single one. Each ballot below is a real Paillier ciphertext — an enormous, genuinely unreadable integer — and the tally at the bottom is computed by multiplying those integers together, never by decrypting a ballot.

This uses a cryptosystem that is additively homomorphic: decrypt(encrypt(a) × encrypt(b)) = a + b. The server can combine votes it cannot read into a total it can. Modulus size is kept small (default 512-bit) so key generation stays interactive — see "what this is not" in the README for why that would not fly in production.

The property that makes this work

Pick two small numbers. This encrypts each one, multiplies the ciphertexts together modulo n², and decrypts the product — with the actual numbers on screen, not a diagram.

Same vote, twice

      

        Encrypt the same option twice. The two ciphertexts differ every
        time — fresh randomness is mixed in on each call — so nobody
        watching the board can tell two voters chose the same option, or
        even that a voter voted the same way as before.
      

      
      

    

  






  
Tally without decrypting

  

    Walk through the homomorphic sum: for each option, multiply every
    ballot's ciphertext for that option together, one at a time. Only the
    final product per option is ever decrypted.
  

  

    
    
  

  

  





  
Verify the result

  

    Anyone with the public and private key can re-run the tally from the
    public board and check it against the announced result — no need to
    trust the tallying party. Corrupt a ballot to see verification catch it.
  

  

    
    
    
  






  
Live benchmark: cost of each Paillier operation

  

    Key generation, encryption, homomorphic addition and decryption, timed
    with performance.now() at several modulus
    sizes, right now in this browser. Homomorphic addition is a single
    modular multiplication — it should be dramatically cheaper than
    encryption, which needs a full modular exponentiation.
