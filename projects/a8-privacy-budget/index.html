Why any of this is necessary

Two queries no reviewer would object to: count of diagnoses in a region, and the same count excluding one age in one postcode. Neither query names anybody. Their difference does.

500 attack attempts at each ε, measured live. 0.5 is a coin flip: the attacker has learned nothing.
